# Current ORBIT development review

Use **orbit-development-review-package.zip**, or download **orbit-development-review.html** alone. Sign in to GitHub, open the file, and click **Download raw** (the download-arrow icon). Extract the ZIP and open the HTML locally. GitHub's source viewer is not the review interface.

- 68 development-only records; no evaluation-event passages/context.
- 23 mechanically clean, 45 quarantined; default Unreviewed + Clean shows 21.
- Automatic local progress saving and a saved-status indicator. Keep the same browser and file location.
- CSV and JSON progress import/export support resuming in another browser or location. Export a backup before moving the file.
- Existing judgments, candidate IDs and AI-assisted/non-independent provenance remain intact.
- Export review CSV after reviewing clean records and return the complete file. All 68 records remain in the export, even when filtered.

**orbit-review-package.zip** is an alias of the new development-only package, replacing the obsolete mixed export at the old download URL. Old versions remain in Git history.
