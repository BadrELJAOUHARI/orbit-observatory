# ORBIT private review downloads

These are byte-identical copies of the existing review exports, prepared because chat artifact downloads failed. No collection or annotation regeneration occurred.

- **orbit-review-package.zip**: consolidated HTML review, CSV and implementation plan.
- **orbit-blind-package.zip**: blind HTML/CSV only; no AI suggestions or prior labels. Give only this package to blind annotators.
- **IMPLEMENTATION_PLAN.md**: plan separately.

Sign in to GitHub, open a ZIP, and click **Download raw** (the download icon). Extract the ZIP, then open its HTML file in your browser. Export responses as CSV before closing.

Keep these source excerpts private. The website files are not part of this delivery commit. SHA256SUMS.txt records the exact download hashes.
