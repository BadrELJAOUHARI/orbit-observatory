# Open this project in Codex

This is a source handoff, not the completed advanced release.

1. Extract the ZIP. The orbit-observatory folder contains the application.
2. For a GitHub-backed Codex Cloud environment, put the contents of that folder in an ORBIT repository you own. Do not upload the ZIP itself as a substitute for the extracted source.
3. In Codex, choose an environment connected to that repository, or create one and connect GitHub as prompted.
4. Ask Codex to read AGENTS.md and docs/HANDOFF.md and carry out the first task listed there.
5. If your chat allows file attachments, you can attach this ZIP for inspection and planning. A chat attachment alone should not be assumed to configure a persistent repository environment.

The methodology and original concept brief are in docs/. No Git history, credentials, or trained model weights are included. The source checkpoint identifier is recorded in docs/HANDOFF.md.
